## Usage

Here are a few examples of how to use ai-agent-workflow-automation:

### Automate a Task

```bash
ai-agent-workflow-automation automate-task --task-name "My Task" --task-description "This is my task"
```

### Analyze a Workflow

```bash
ai-agent-workflow-automation analyze-workflow --workflow-name "My Workflow" --workflow-description "This is my workflow"
```

### Collaborate with Team Members

```bash
ai-agent-workflow-automation collaborate --team-members "John Doe, Jane Doe" --workflow-name "My Workflow"
```

## Configuration

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `--task-name` | string |  | The name of the task to automate |
| `--task-description` | string |  | A description of the task to automate |
| `--workflow-name` | string |  | The name of the workflow to analyze |
| `--workflow-description` | string |  | A description of the workflow to analyze |
| `--team-members` | string |  | A list of team members to collaborate with |
